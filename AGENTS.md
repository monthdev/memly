# Memly Agent Instructions

Before analyzing or modifying Memly code, architecture, build configuration, or
developer documentation, read and follow `documentation/agents/CODING_GUIDE.md`.

Before analyzing or modifying CMake configuration, read and follow
`documentation/agents/CMAKE_MAINTENANCE_GUIDE.md`.

Before creating, pruning, or updating a patch artifact, read and follow
`documentation/agents/PATCH_ARTIFACTS_GUIDE.md`.

Before creating, renaming, pruning, or updating a guide under
`documentation/agents/`, read and follow `documentation/agents/META_GUIDE.md`.

Before proposing or modifying local agentic coding hooks, consult
`documentation/agents/recommendation/HOOKS_RECOMMENDATION_GUIDE.md`.

Before proposing or modifying an editor linting integration, consult
`documentation/agents/recommendation/LINTING_SETUP_RECOMMENDATION_GUIDE.md`.
